# Changelog

## 0.1.0

First release.

- Edge-mounted glass rail (iPhone Duo style) that unfolds into a liquid-glass panel.
- Live Claude plan usage through Claude Code's `get_usage` request.
- Live Codex plan usage through `codex app-server`.
- Session and weekly gauges with reset times; exact token counts from local logs.
- Light, dark and Auto themes; spring animations; click-through outside the glass.
- Usage alerts at a threshold you choose; tray icon; start with Windows.
- Optional Claude Code status line showing your limits.
- Signed auto-updates via GitHub releases.
